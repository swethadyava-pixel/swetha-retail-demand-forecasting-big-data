# Evidence to capture from your own tools

The guidelines require genuine working outputs. Capture these after running the project in your own environment; do not use mock screenshots as execution proof.

- `postgresql_dbeaver/`: connection, schema/tables, at least 3 SQL result grids.
- `python/`: notebook executed with outputs and at least 3 charts.
- `databricks/`: notebook run, Bronze/Silver/Gold Delta outputs, and one aggregation.
- `powerbi/`: interactive dashboard screenshot(s), and the `.pbix` if sharing is permitted.
- `github/`: repository home page after upload.

Use only screenshots that you actually captured. Never include credentials, API keys, access tokens or sensitive data.
